# Advanced-Database-Porfolio--Emmanuel-Uzochukwu-Ugwumba
Design, Implementation, Optimisation and Management of an Advanced Banking Database System for Corporate Banking Operations.
Nature of the Business/System
Zorch Bank PLC is used as the case-study organisation for a relational and distributed database system designed to support corporate banking operations. The proposed system will manage corporate customers, bank accounts, deposits, withdrawals, inter-account transfers, transaction records, and audit logs. For academic purposes, all customer identities, account numbers, balances, and transaction records used in the implementation will be synthetic.
